🔀 If / Else Bertingkat

Satu keputusan bisa punya banyak cabang dan banyak syarat.

KONSEP

if, else if, else

if mengecek kondisi pertama. Jika salah, lanjut ke else if. else menangkap sisanya. Dibaca dari atas ke bawah, berhenti di cabang pertama yang benar.

if (suhu > 35) kipas = 255;
else if (suhu > 28) kipas = 120;
else kipas = 0;
💡 Suhu 40 juga memenuhi > 28, tapi tidak jalan karena cabang pertama sudah kena. Urutan = prioritas.
OPERATOR

&& (DAN) · || (ATAU) · ! (NOT)

&& true jika kedua sisi true. || true jika salah satu true. ! membalik nilai. Pembanding: == != < > <= >=.

if (tombol && gelap) led = FULL;
if (tombol || gelap) led = REDUP;
⚠ if (x = 5) itu mengisi x, bukan membandingkan. Pakai ==.

〰️ Sinyal Digital vs Analog

Dunia nyata itu halus, bukan cuma ON dan OFF.

DIGITAL

Dua keadaan

Hanya HIGH (5V) atau LOW (0V). Cocok untuk tombol dan LED on/off.

ANALOG

Nilai kontinu

Tegangan bisa berada di mana saja antara 0-5V: putaran knob, cahaya, suhu, posisi.

ADC

Arduino mengubah analog → angka

Arduino hanya mengerti angka. ADC 10-bit membagi 0-5V menjadi 210 = 1024 level (0-1023). Satu level ≈ 5V/1024 ≈ 4,88 mV. Pin analog: A0-A5.

int nilai = analogRead(A0); // 0 - 1023
float volt = nilai * 5.0 / 1023.0; // jadi Volt

Garis kuning = hasil ADC (bertangga), putus-putus = sinyal asli.

🎛️ Potensiometer

Sensor analog paling sederhana: resistor yang bisa diputar.

KONSEP

Voltage divider

Potensiometer punya 3 kaki: dua kaki ujung (ke 5V dan GND) dan satu kaki tengah (wiper) yang keluar sebagai sinyal. Memutar knob menggeser wiper sehingga tegangannya berubah dari 0V sampai 5V.

Vout = Vin × R2 / (R1 + R2)
💡 Kaki ujung ke 5V dan GND tertukar = hanya arah putar terbalik, tidak rusak. Tapi kaki tengah harus ke A0.

📈 PWM · Pulse Width Modulation

Cara Arduino "mengatur kekuatan" output digital.

KONSEP

ON-OFF sangat cepat

Uno tidak punya output analog asli. PWM menyalakan dan mematikan pin ± 490 kali per detik (pin 5 & 6: ± 980 Hz). Mata kita tidak melihat kedipan, hanya rata-rata terang.

Duty cycle = persen waktu ON dalam satu periode. Tegangan rata-rata = duty × 5V.

analogWrite(pin, 0); // 0% → 0 V
analogWrite(pin, 64); // 25% → 1,25 V
analogWrite(pin, 127); // 50% → 2,5 V
analogWrite(pin, 191); // 75% → 3,75 V
analogWrite(pin, 255); // 100% → 5 V
💡 Hanya pin bertanda ~: 3, 5, 6, 9, 10, 11. Dipakai untuk dimmer LED, kecepatan motor, dan servo.

Waveform Lab

Nilai analogWrite

🔌 Contoh Rangkaian · Dimmer LED

Gambar acuan untuk dirakit di breadboard sungguhan.

Skema

Merah = 5V · Abu = GND · Hijau/Kuning = sinyal

Langkah rakit

1Pot di breadboard, kaki kiri → 5V
2Kaki kanan → GND
3Kaki tengah → A0
4D9 → resistor 220Ω → LED (+) ; LED (−) → GND
const int POT = A0, LED = 9;
void setup() { Serial.begin(9600); }
void loop() {
  int nilai = analogRead(POT);
  int pwm = map(nilai, 0, 1023, 0, 255);
  analogWrite(LED, pwm);
  Serial.println(pwm);
}

Simulasi: putar potensiometer

Pot

Kalau tidak jalan, cek urutan ini

1) LED tidak berubah terang → pin LED bukan pin ~. 2) Selalu terang penuh / mati → kaki tengah pot tidak ke A0. 3) Serial menampilkan 0 terus → kaki 5V atau GND pot lepas. 4) LED mati total → polaritas LED terbalik.

📏 HC-SR04 · Sensor Jarak

Mengukur jarak dengan memantulkan bunyi ultrasonik.

PRINSIP KERJA

Seperti sonar kelelawar

1) Arduino memberi pulsa 10 µs ke pin TRIG. 2) Sensor memancarkan 8 gelombang 40 kHz. 3) Pin ECHO menjadi HIGH sampai pantulan kembali. 4) pulseIn() mengukur lama HIGH itu.

jarak = durasi × 0,034 / 2 // cm
jarak = durasi / 58 // versi singkat
Dibagi 2 karena bunyi pergi dan pulang. Jangkauan 2-400 cm. Pin: VCC (5V), TRIG, ECHO, GND. Library NewPing: sonar.ping_cm().

🌡️ DHT11 · Suhu & Kelembaban

Dua sensor dalam satu modul, data lewat satu kabel.

SPESIFIKASI

Cara pakai

Suhu 0-50°C (±2°C), kelembaban 20-90% (±5%). Kirim data digital lewat 1 pin DATA dengan protokol sendiri, jadi wajib pakai library DHT. Baca maksimal 1× per detik. Pin: VCC, DATA, GND.

#include <DHT.h>
DHT dht(4, DHT11);
float t = dht.readTemperature();
float h = dht.readHumidity();
if (isnan(t) || isnan(h)) return;
⚠ Pembacaan gagal menghasilkan NaN. Selalu cek dengan isnan() sebelum dipakai di if/else.

🔌 Contoh Rangkaian · Alarm Jarak + Indikator Suhu

Gambar acuan, rakit di breadboard sungguhan.

Skema

Tabel pin

HC-SR04: VCC→5V · TRIG→D2 · ECHO→D3 · GND→GND
DHT11: VCC→5V · DATA→D4 · GND→GND
Buzzer: (+)→D8 · (−)→GND
LED: D9→220Ω→LED(+) · LED(−)→GND
void loop() {
  int jarak = sonar.ping_cm();
  float t = dht.readTemperature();
  if (jarak > 0 && jarak < 30) tone(8, 1000);
  else noTone(8);
  if (!isnan(t)) digitalWrite(9, t > 30);
  Serial.println(jarak);
  delay(500);
}
